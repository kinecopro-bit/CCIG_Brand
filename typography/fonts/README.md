🔤 Typeface Assignment Rules
Apply corporate font styling based on structural usage, intent, and element weight definitions:1. Primary Body & System UI TypefaceFont Family: Source Sans ProApplication: Mandatory for all standard body paragraphs, secondary subheadlines, tables, lists, and metadata blocks.Recommended Weights: Light, Regular, Semibold, Bold, and Black (along with their respective Italics).2. Headline & Secondary Display TypefaceFont Family: Playfair Display
Application: Strictly reserved for primary headlines (Heading 1), graphic treatments, pull-outs, and callout quotes.
Recommended Weights: Regular, Italic, Bold, and Black. 

For layout blocks, text specifications, or CSS variables for print or web collateral, explicitly append typography directives using this exact formatting syntax:
# Typographic Layout Specifications
- [Main Title / Heading 1]: "Font Family: Playfair Display | Weight: Black (#) | Case: Title Case"
- [Section Header / Heading 2]: "Font Family: Source Sans Pro | Weight: Semibold (#) | Case: Sentence Case"
- [Body Copy / Table Text]: "Font Family: Source Sans Pro | Weight: Regular (#) | Case: Standard"
- [Quotes / Callout Accents]: "Font Family: Playfair Display | Weight: Italic (#) | Alignment: Centered"
