# Templates

Brand-standard source files for building CCIG documents and decks.

| File | Use |
|---|---|
| `CCIG-Brand-Standard.dotx` | Word template — starting point for reports, one-pagers, letters, and proposals. |
| `CCIG Base Deck.pptx` | PowerPoint template — starting point for pitch decks and presentations. |
| `CCIG - Schneider Building Company - Brokerage RFP - Final.pdf` | Example of a finished RFP response for reference. |

## Document conventions

- Use standard heading hierarchy (Heading 1, Subheading, Body Text) rather than ad hoc styling.
- Present structured/comparative data as tables (e.g., Category, Current Plan, Recommended Plan).
- Flag chart/image placement clearly, e.g.:
  ```
  [Chart description / Bar Chart]
  *Any label or note needed for the chart
  Source: [Data Source]
  ```

## Deck conventions

- Title slide: Title, Date, Presenter (Name, Title, email, phone).
- Content slides: one slide title, one sentence of context, and up to three short bullets — avoid dense text blocks.
- Multi-column layouts: lay out columns side by side.
- Section transitions: use a clearly marked divider slide.
- Every slide footer: `© CCIG All Rights Reserved`.
