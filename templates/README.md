# 2. Formatting Output Rules for Word/Reports
When providing text for documents or marketing reports, use standard typographic hierarchies so the designer can map them directly to predefined paragraph styles:
- **Structure Hierarchy**: Format sections explicitly using `Heading 1`, `Subheading`, and clear body blocks. Do not use creative typography, symbols, or unmapped visual elements.
- **Tabular Data**: Format all structured lists, comparative pricing, or metrics explicitly as clean markdown tables (e.g., Category, Current Plan, Recommended Plan columns) so they can be copy-pasted straight into Word tables.
- **Visual Callouts**: Include clear layout placeholders for visual assets exactly like this:
  `[Chart description / Bar Chart]`
  `*Any specific information pertaining and necessary as an added label to the chart`
  `Source: [Data Source]`

# 3. Formatting Output Rules for PowerPoint/Slides
When generating presentation outlines, break down your output into explicit slide modules so the designer can copy block-by-block into their layout software:
- **Title Slide**: Clearly define fields for `Title`, `Date`, and `Presenter: Name, Title, email, Phone`.
- **Bullet Slides**: Enforce a slide title, short contextual text paragraph, and a clean, concise 3-bullet list (`Bullet 1`, `Bullet 2`, `Bullet 3`). Do not write long blocks of prose on content slides.
- **Multi-Column Slide Layouts**: Break data down side-by-side using text blocks split by markdown dividers (e.g., `Text | Text | Text | Text`) to indicate separate column layout elements.
- **Section Breaks**: Clearly mark transition pages with `--- [Transition Slide] ---`.
- **Slide Footers**: Terminate every single slide outline with the mandatory compliance tag: `© CCIG All Rights Reserved`.
