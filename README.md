# CCIG Brand Repository

This repository is the source of truth for CCIG's visual identity and brand assets: logos, color palette, typography, illustrations, and document/deck templates.

## About CCIG

Since 1985, CCIG has been a fiercely independent, rapidly growing insurance brokerage, delivering comprehensive risk management and insurance solutions to our diverse clientele. With a national presence, we employ over 100 seasoned insurance professionals and operate from our offices in Denver, CO, Austin, TX, and Phoenix, AZ. CCIG is a full-service Private Client, Commercial Lines, and Employee Benefits insurance brokerage.

Our three core service pillars:
- Private Client
- Property & Casualty / Commercial Lines
- Employee Benefits

## Repository structure

| Folder | Contents |
|---|---|
| `logos/` | Primary, reverse, and monochrome logo files. See `logos/README.md` for usage rules. |
| `color-palette/` | Brand color swatches and reference PDF. See `color-palette/swatches/README.md`. |
| `typography/` | Brand fonts and type usage guidance. See `typography/fonts/README.md`. |
| `templates/` | Word and PowerPoint brand templates. See `templates/README.md`. |
| `illustrations/` | Vector illustration assets for use in collateral. |
| `checklists/` | Client-facing checklists and reference documents. |
| `Monthly Recap/` | Monthly recap collateral, organized by month. |
| `Head Shots/` | Team headshot photography. |

## Quick reference

**Logo:** use `logos/primary/CCIG-Color-Horizontal-RGB.png` on light backgrounds, `logos/primary/CCIG-Reverse-Horizontal-RGB.png` on dark backgrounds, and the monochrome variants in `logos/monochrome/` only when a single-color mark is specifically needed.

**Color palette** (see `color-palette/swatches/README.md` for full CMYK/PMS values):
CCIG Green #8FB24E · CCIG Light Blue #366E8E · CCIG Yellow #FFC666 · CCIG Dark Blue #153243 · CCIG Grey #BFC7CB · CCIG Light Grey #EDECED · White #FFFFFF

**Typography** (see `typography/fonts/README.md`):
Headlines/callouts — Playfair Display. Body text/tables/UI — Source Sans Pro.
