# CCIG Typography

Font files are provided in `CCIG Fonts.zip`. Full specimens and pairing guidance are in `CCIG Brand Colors And Typography.pdf`.

## Typefaces

**Playfair Display** — headline/display typeface. Use for Heading 1 / primary titles, callout quotes, and graphic pull-out treatments. Weights: Regular, Italic, Bold, Black.

**Source Sans Pro** — body and UI typeface. Use for body paragraphs, subheadings, tables, lists, and metadata. Weights: Light, Regular, Semibold, Bold, Black (with italics).

## Suggested hierarchy

| Element | Font | Weight | Case |
|---|---|---|---|
| Main title / Heading 1 | Playfair Display | Black | Title Case |
| Section header / Heading 2 | Source Sans Pro | Semibold | Sentence case |
| Body copy / table text | Source Sans Pro | Regular | Standard |
| Quotes / callout accents | Playfair Display | Italic | Centered |
