# Logo Usage

| Background | Logo file |
|---|---|
| Light | `primary/CCIG-Color-Horizontal-RGB.png` |
| Dark | `primary/CCIG-Reverse-Horizontal-RGB.png` |
| Monochrome (single-color contexts only) | `monochrome/CCIG-Dark-Blue-Horizontal-RGB.png`, `monochrome/CCIG-Light-Blue-Horizontal-RGB.png`, or `monochrome/CCIG-White-Horizontal-RGB.png` as appropriate for the background |

Maintain clear space around the logo and do not stretch, recolor, or otherwise distort the mark. Submark variants live in `submarks/` when a compact/icon-only treatment is needed.
